# ESTOQUE DE TECIDO PLUS+ V40

Versão limpa, sem login, preparada para Render.

## Render
- Runtime: Node
- Build: `npm install`
- Start: `npm start`
- Health: `/api/health`
- Porta: variável `PORT` (Render fornece automaticamente)

Não é necessário configurar senha ou variável de ambiente para iniciar.
